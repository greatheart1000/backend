# RAG知识库系统项目总结

## 项目概述

本项目实现了一个基于Redis缓存的六阶段RAG（Retrieval-Augmented Generation）管道系统，旨在提供高效、准确的问答服务。系统通过意图识别、上下文管理、混合检索、精排融合、答案生成等多个阶段，结合多级缓存策略，显著提升了查询处理效率和答案质量。

## 核心功能

### 1. 六阶段处理管道

系统采用六阶段处理流程，每个阶段都有明确的职责和优化策略：

1. **意图与权重分析**：识别用户查询意图并动态分配检索权重
2. **向量化与会话管理**：将查询转换为向量表示并管理会话上下文
3. **混合检索（粗排）**：结合BM25和向量检索的优势进行初步筛选
4. **精排与融合**：使用RRF融合和BGE精排模型优化排序结果
5. **答案生成**：基于检索结果生成自然语言答案
6. **结果返回与缓存**：返回答案并更新缓存和会话历史

### 2. 多级缓存优化

系统实现了五级Redis缓存，显著减少重复计算：

- **缓存A**：意图识别结果缓存
- **缓存B**：检索候选列表缓存
- **缓存C**：最终答案缓存
- **缓存D**：查询向量缓存
- **缓存E**：会话历史缓存

### 3. 模块化架构

系统采用模块化设计，各组件职责清晰：

- **意图识别模块**：基于预训练模型进行意图分类
- **上下文管理模块**：处理查询向量化和会话历史
- **动态检索模块**：执行混合检索策略
- **精排与融合模块**：优化检索结果排序
- **答案生成模块**：生成自然语言答案
- **缓存管理模块**：统一缓存接口

## 技术特点

### 1. 混合检索策略

系统结合了传统BM25检索和现代向量检索的优势：
- BM25擅长关键词匹配和精确检索
- 向量检索擅长语义理解和模糊匹配
- 动态权重分配根据查询意图调整两种检索的比重

### 2. RRF融合算法

采用倒数排名融合（Reciprocal Rank Fusion）算法：
- 有效结合多个检索系统的优点
- 不需要复杂的参数调优
- 提升了检索结果的多样性和准确性

### 3. BGE精排模型

使用BAAI/bge-reranker-base模型进行精排：
- 基于交叉编码器架构
- 能够捕捉查询和文档间的细粒度交互
- 显著提升排序质量

### 4. 会话上下文管理

实现了智能会话上下文管理：
- 滑动窗口机制维护会话历史
- 上下文感知的查询增强
- 个性化的对话体验
